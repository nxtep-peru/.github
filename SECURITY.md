# Seguridad

Si encuentras una vulnerabilidad en algo de Nxtep, ya sea una de sus
aplicaciones o uno de sus repos, repórtala en privado:

**[Reportar una vulnerabilidad](https://github.com/nxtep-peru/.github/security/advisories/new)**

El reporte llega solo a quienes administran la organización, y la
conversación sigue ahí mismo, en privado. No lo publiques en un issue, un
pull request ni una red social mientras no esté resuelto.

Para que podamos reproducirlo, cuéntanos qué encontraste, dónde (la URL,
la pantalla o el endpoint) y los pasos para verlo. No hace falta un
exploit completo.

Mientras investigas, no accedas a datos de otras personas, no los
modifiques y no afectes el servicio.
