# Nxtep

Nxtep es una comunidad de Producto y Growth que conecta a sus miembros con
mentorías, eventos y recursos para impulsar su carrera. Aquí vive el
trabajo de su equipo de desarrollo, que construye los productos de la
comunidad y de sus emprendimientos.

## Cómo trabajamos

- **Todo cambio entra por pull request**, desde ramas cortas sobre `main`.
- **Historial legible**: commits y títulos de PR en Conventional Commits,
  integrados con squash, un commit por cambio.
- **Tickets con estructura**: los issues se abren con formularios por
  tipo (Bug, Feature y Task) y se planifican en GitHub Projects.
- **IA con guardas**: desarrollamos con Claude Code sobre una
  configuración compartida que impide commitear directo a `main`, forzar
  un push o leer secretos. Lo que escribe un asistente se revisa igual que
  lo que escribe una persona.
- **Secretos fuera de git**: cada repo documenta sus variables y los
  valores reales se comparten en privado.

La guía completa está en
[CONTRIBUTING.md](https://github.com/nxtep-peru/.github/blob/main/CONTRIBUTING.md),
y cómo reportar una vulnerabilidad, en
[SECURITY.md](https://github.com/nxtep-peru/.github/blob/main/SECURITY.md).
